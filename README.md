# ExpenseTrack – Personal Expense Management System

A responsive personal finance dashboard built with **HTML5, CSS3 and vanilla JavaScript**. All data is saved in the browser's **LocalStorage**; no backend or database is needed.

## Features
- Dashboard: total balance, income, expenses, monthly savings, live Chart.js charts, recent transactions
- Full CRUD for income and expenses with category, amount, date and description
- Transactions page with search and filters (type, category, month, date)
- Analytics: monthly income/expense reports, category breakdown, 6-month comparison, savings rate
- Export transactions to CSV, download a monthly report
- Form validation, delete confirmation, empty states
- Sample data for first-time demo (removable), clear-all option
- Currency: Indian Rupees (₹), `en-IN` formatting

## Tech Stack
HTML5 · CSS3 · Vanilla JavaScript · LocalStorage · Chart.js (CDN) · Font Awesome (CDN)

## Run Locally
Open `index.html` in any modern browser.

## Deploy on GitHub Pages
Repository → **Settings → Pages → Deploy from a branch → main / (root)** → Save.
